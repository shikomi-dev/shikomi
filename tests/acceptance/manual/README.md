# 実画面の確認

## EX-SC001-03 ロック中の停止

Ubuntu 24.04 / 26.04の通常のログインセッションで定型文を登録する。入力先のアプリを開き、画面をロックして登録キーを押す。ロック解除後に文字列が勝手に貼り付けられていないことを確認する。解除後に改めてキーを押したときだけ貼り付ける。個人情報を含まない入力欄だけを録画する。未実行は未確認と記載する。

## 操作録画

登録の端末対話はVHSで記録し、別アプリへの貼り付けはGNOMEの対象範囲録画で記録する。初期化した起点には入口がないため変更後のみ。録画と両OSの実行結果はPRに置き、動画をリポジトリへコミットしない。
