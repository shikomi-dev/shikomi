# 文字列を登録して使う

## 目的と入口

アプリ一覧からshikomiを開き、「追加」でラベルと本文を入力し、キー設定で実際の組み合わせを押して離して保存します。別アプリの入力欄でそのキーを押すと本文が入ります。一覧で選んで変更し、保存すると次の貼り付けから反映します。削除は選択中の登録のメニューから確認して行います。

未保存のまま移動・取消し・終了しようとした場合は破棄するか確認します。外観はライト・ダーク・システム追従を選べます。狭い画面では一覧を引き出して選びます。

Ubuntuの利用者が繰り返し入力する文章を登録し、編集中のアプリで貼り付けます。端末で `shikomi add <文字列>` を実行し、キーを実際に押して離し、ラベルを入力します。別アプリの入力欄へ移り、そのキーを押すと文字列が入ります。

編集は `shikomi edit <ラベル>`。文字列・キー・ラベルを対話で変更します。削除は `shikomi remove <ラベル>`。一覧は `shikomi list` でラベルとキーだけを返します。

## 成功時の保証

保存直後から新しい登録が使えます。変更前のキーは解除され、削除したキーで文字列を貼り付けません。保存した登録は次の拡張起動でも復元されます。貼り付けはShift+Insertを受け付けるアプリに対して行います。

## 最低保証

画面での保存結果が通信断で確認できなければ、入力を保ち、成功扱いや再送をしません。保存内容を読み直してから再開します。拡張が利用できない間は有効と表示せず、再接続する操作を示します。

取消し、不正値、重複、OSのキー競合、保存失敗では既存の登録を保持します。編集を始めた後に他の操作で登録が変更されていたら上書きしません。キーを離す前にアプリが変わったときや画面ロック中には貼り付けません。
