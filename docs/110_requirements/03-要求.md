# 要求

アプリ一覧または `shikomi-gui` から画面を開き、ラベルとキーの一覧から定型文を選び、本文・ラベル・キーを編集します。追加・削除も画面から行えます。ライトとダークで配置を共通にし、狭い画面とキーボード操作にも対応します。未保存の離脱では確認し、拡張への接続状態と保存結果を区別して表示します。

`shikomi add <文字列>` の次の行でキー入力を待ち、実際のキーの組み合わせを読み取った後でラベルを尋ねます。保存した組み合わせを別アプリで押すと文字列を貼り付けます。`shikomi edit <ラベル>` で文字列・キー・ラベルを編集し、`shikomi remove <ラベル>` で登録を削除します。ラベルとキーの重複を拒みます。

初版の対象はUbuntu 24.04 / 26.04の標準GNOMEです。Windows、macOS、他デスクトップ、履歴収集、暗号化、旧データ移行、Homebrew配布は含めません。
