# INC-7 外観を選択した直後に配色を反映する

対応Issue: #7

## 変更範囲

外観メニューからライトとダークを選ぶと、画面全体の配色を次のフレームへ反映する。メニューの開閉、配色、外観設定の保存方法は変更しない。0.0.3を署名付きaptで配布する。

## 設計と確認

Flutterのアプリ全体を包むテーマで、配色の補間時間をゼロにする。既存の外観の受入例でライトとダークを交互に選び、次のフレームから選択した配色を使うことと、保存した選択を復元できることを確認する。配布版と検証版を同じGNOME Waylandセッションで切り替え、描画とメニューが閉じるまでを実測する。

## 結果のありか

計測条件と観測結果は、[Issue #7](https://github.com/shikomi-dev/shikomi/issues/7)を閉じるPRに記載する。
