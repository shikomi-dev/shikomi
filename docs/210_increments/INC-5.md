# INC-5 定型文を画面から管理する

対応Issue: #5

## 変更範囲

採用したライト・ダークの画面から、検索、追加、編集、削除、実際のキーによる割り当てを行う。未保存の離脱、重複、拡張への接続失敗を画面で説明する。CLIは継続して使える。

## 設計と確認

Flutterの画面を `client/shikomi/gui` に置く。保存とキー取得は既存の公開D-Bus契約へ接続し、ファイルへ直接書き込まない。画面の編集中の値と保存済みの値を分け、通信断による結果不明は再取得まで再送を止める。削除にも編集前の値を渡し、他の入口で変更された内容を削除しない。

画面の操作はFlutterの実画面テストから行い、隔離したGNOMEでキー取得と別のGTKアプリへの貼り付けを通す。画面内の分岐はウィジェットテスト、通信の拒否と応答検証は境界テストで確かめる。日本語、テーマ、狭い画面、未保存の離脱、拡張無効を確認する。初回と再ビルドの所要時間を測り、PRに観測値を記載する。

## 結果のありか

対応PRは作成後に記載する。採用した画像と生成指示は作業用 `output/imagegen` に保管し、実装の動作確認結果と区別する。
