# INC-3 Release公開からapt導入へつなぐ

対応Issue: #3

## 変更範囲

GitHub Releaseのpublishedイベントで同じ版のdebと署名付きapt配布元を発行します。利用者は初回の配布元登録後、aptの通常の操作で導入・更新します。pre-pushで自動検査を必ず実行します。

## 設計と確認

VERSIONを配布版の正本にし、タグが違えばパッケージを作りません。秘密鍵はGitHub ActionsのSecretへ置き、コードには公開鍵だけを持たせます。鍵の指紋（鍵を一意に指す値）が一致しない場合も公開しません。

シェルに貼り付けた内容が実行される入口までをGNOME Terminalで検査します。登録時と変更後のコマンドの結果をファイルで観測し、削除後は同じキーで結果が更新されないことを確認します。リリース後には公開aptから導入したCLIでも同じ操作を行います。

## 結果のありか

対応PRとv0.0.1のReleaseに公開結果を残します。
