## 5. `zxcvbn` 強度評価仕様（R1-GUI-10）

`zxcvbn(password)` の出力オブジェクトから以下を使用する。

| 出力フィールド | 用途 |
|---|---|
| `score` (0〜4) | プログレスバー + ボタン有効 / 無効制御 |
| `feedback.warning` (string) | 警告テキスト表示（非空時のみ） |
| `feedback.suggestions` (string[]) | 改善提案リスト表示（非空時のみ） |

| `score` | 強度ラベル | 「暗号化」ボタン |
|---------|-----------|--------------|
| 0 | 非常に脆弱 | disabled |
| 1 | 脆弱 | disabled |
| 2 | 普通 | disabled |
| 3 | 強い | **enabled** |
| 4 | 非常に強い | **enabled** |

**スコア閾値の根拠**: `zxcvbn` の score ≥ 3 は "safely unguessable" に相当（出典: https://github.com/dropbox/zxcvbn#readme）。feature-spec R1-GUI-10 の「強度 ≥ 3 でボタン有効化」と整合。

## 6. `lib/errors.ts` — エラー変換責務

`errors.ts` が `GUIError` オブジェクトを受け取り、Sub-C が表示すべき日本語メッセージ（または `null`、制御フロー用エラー種別）を返す単一変換モジュール。

| 入力 | 戻り値の種類 | 備考 |
|------|------------|------|
| `{ kind: "daemon_not_running" }` | 日本語文字列 | 「daemon が起動していません…」 |
| `{ kind: "ipc_error", ipc_code: "vault_locked" }` | 制御フロー信号 | コンポーネントは `UnlockModal` 表示に切り替える |
| `{ kind: "ipc_error", ipc_code: "hotkey_conflict", hotkey_conflict_entry: "..." }` | 日本語文字列 | 競合エントリ名を文字列補間 |
| `{ kind: "ipc_error", ipc_code: "crypto", crypto_reason: "..." }` | 日本語文字列 | `crypto_reason` で分岐 |
| `{ kind: "ipc_error", ipc_code: "backoff_active", wait_secs: N }` | 日本語文字列 | `wait_secs` を文字列補間 |
| `{ kind: "invalid_input" }` | 日本語文字列 | `message` の内容から変換（`errors.ts` 内マッピング表）|

**`message` フィールドを戻り値に含めてはならない**。`errors.ts` が変換責務を一手に担い、コンポーネントは変換後の文字列のみを受け取る。

## 7. UX 上の考慮

### 7.1 ペルソナ A/C への配慮

田中俊介（ペルソナ A）・佐々木健二（ペルソナ C）はいずれも技術知識不要層。以下を遵守する:
- 英語技術文字列（`message` フィールド・UUID・エラーコード等）を画面に表示しない
- 「vault」「IPC」等の技術用語は「shikomi のデータ」「パスワード保護」等の平易表現に言い換える
- エラー回復方法（「`shikomi start` を実行してください」等）を必ず添えて表示する

### 7.2 MVP 非スコープ

| 項目 | 理由 |
|------|------|
| アクセシビリティ（WCAG 2.1 AA / `aria-*`）| feature-spec §6 で別 Issue 扱いと確定 |
| i18n / 多言語対応 | feature-spec §4（MVP は日本語 UI のみ）|
| ダーク / ライトモード切替 | feature-spec §6 MVP 後回し |

## 8. ビジュアルデザイン

### 8.1 デザイントークン

`App.css` にて CSS カスタムプロパティとして一元定義する。コンポーネントはこれらのトークンを参照し、色値・サイズのハードコードを禁止する。

#### カラーパレット

| トークン名 | 値 | 用途 |
|---|---|---|
| `--color-bg` | `#f5f5f5` | アプリ全体の背景 |
| `--color-surface` | `#ffffff` | カード・パネル・モーダルの背景 |
| `--color-border` | `#e0e0e0` | ボーダー・セパレータ |
| `--color-text-primary` | `#212121` | 主要テキスト |
| `--color-text-secondary` | `#757575` | 補助テキスト・キャプション |
| `--color-primary` | `#1976d2` | プライマリボタン・リンク |
| `--color-primary-hover` | `#1565c0` | プライマリボタン hover |
| `--color-primary-disabled` | `#90caf9` | disabled ボタン |
| `--color-danger` | `#d32f2f` | 削除ボタン・エラーメッセージ |
| `--color-danger-hover` | `#b71c1c` | 削除ボタン hover |
| `--color-warning` | `#f57c00` | 警告テキスト |
| `--color-error-bg` | `#ffebee` | インラインエラー背景 |
| `--color-error-text` | `#c62828` | インラインエラーテキスト |

#### VaultStatusBanner 専用トークン（4 状態）

| トークン名 | 値 | 状態 |
|---|---|---|
| `--color-vault-plaintext-bg` | `#fff3e0` | `plaintext`（橙色：平文 = 注意状態）|
| `--color-vault-plaintext-text` | `#bf360c` | 同上 |
| `--color-vault-locked-bg` | `#e3f2fd` | `encrypted_locked`（青色：ロック中）|
| `--color-vault-locked-text` | `#0d47a1` | 同上 |
| `--color-vault-unlocked-bg` | `#e8f5e9` | `encrypted_unlocked`（緑色：安全・解除済）|
| `--color-vault-unlocked-text` | `#1b5e20` | 同上 |
| `--color-vault-unknown-bg` | `#f5f5f5` | `unknown`（灰色：状態不明）|
| `--color-vault-unknown-text` | `#424242` | 同上 |

**色と文言の二重表現**: バナーは色だけでなく文言（`[平文]` / `[暗号化済・ロック中]` 等）でも状態を表す。色覚多様性への配慮として文言単独でも判別可能な設計にする（§7.2 MVP 非スコープのアクセシビリティは WCAG AA 準拠は後回しだが、色依存の排除は今から行う）。

#### strength メーター専用トークン（zxcvbn score 0〜4）

| トークン名 | 値 | score |
|---|---|---|
| `--color-strength-0` | `#ef5350` | 0（非常に脆弱）|
| `--color-strength-1` | `#ff7043` | 1（脆弱）|
| `--color-strength-2` | `#ffa726` | 2（普通）|
| `--color-strength-3` | `#66bb6a` | 3（強い）|
| `--color-strength-4` | `#43a047` | 4（非常に強い）|

| トークン名 | 値 | 用途 |
|---|---|---|
| `--font-family` | `system-ui, -apple-system, "Segoe UI", sans-serif` | 全テキスト（OS ネイティブフォント優先）|
| `--font-size-heading` | `18px` | セクション見出し・パネルタイトル |
| `--font-size-subheading` | `15px` | サブ見出し・テーブルヘッダ |

### 8.3 スペーシンググリッド

**8pt グリッド** を採用する。全マージン・パディング・コンポーネント間隔は 8pt の倍数で指定する。

| トークン名 | 値 | 用途例 |
|---|---|---|
| `--space-1` | `4px` | アイコンとラベルの間・バッジ内パディング |
| `--space-2` | `8px` | フィールドラベルとインプットの間・ボタン内水平パディング |
| `--space-3` | `16px` | パネル内部パディング・フォームフィールド間 |
| `--space-4` | `24px` | セクション間・主要コンポーネント間 |
| `--space-5` | `32px` | パネルとウィンドウ端の余白 |
| `--space-6` | `48px` | モーダルオーバーレイ上下余白 |

**ボーダー半径**:

| トークン名 | 値 | 用途 |
|---|---|---|
| `--radius-sm` | `4px` | バッジ・インラインエラー背景 |
| `--radius-md` | `8px` | ボタン・インプット・パネルカード |
| `--radius-lg` | `12px` | モーダルウィンドウ |
