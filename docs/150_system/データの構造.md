# データの構造

GNOME拡張だけが保存を所有します。XDG_DATA_HOME配下の `shikomi/entries.json` に形式の版と登録の配列を保存します。一件は `label`、`text`、`key`。ラベルとキーはそれぞれ一意で、空のラベル・文字列、制御文字を含むラベルを拒否します。

ファイルは所有者のみ読み書きできる権限で丸ごと置き換えます。キーの取得失敗は保存前に返し、保存失敗では新しく取得したキーを解除します。保存が成功してから古いキーを解除します。未知の版や壊れたデータは上書きせず、拡張起動を失敗させます。

編集には読み取り時の一件を添え、現在値が変わっていれば拒否します。鍵は文字列を実行するためのコマンドではありません。貼り付け文字列をシェル評価しません。

GUIの外観選択だけはXDG_CONFIG_HOME配下の `shikomi/appearance` へ保存します。登録本文を複製しません。
